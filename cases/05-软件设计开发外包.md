## 我们怎么做

1. **需求对接**：拿你的技术方案和甲方需求，出功能对照表：哪些能做、哪些做不了，先说清。
2. **按 7 段报价**：需求对接 / 页面设计 / 三维制作及渲染 / 前端 / 后台对接 / 测试 / 培训，每段多少钱、多少天摊开给你看。
3. **分段交付**：三维先出场景样片，前端先出可点原型，后台先跑通一个接口，每段都看得见东西。
4. **联调、测试、部署**：跟你方项目经理一起联调，出测试记录；内网一套、公网一套，机房和办公室都能跑。
5. **交源码、做培训**：源代码、源文件、文档一起交，教会甲方的人自己维护。

## 交付物清单

- **两套开发源代码（内网 / 公网）+ 可直接运行的源文件**
- 三维场景模型与工程文件
- 前端、后台、接口与部署文档
- 测试记录与用户培训
- 按 7 段拆的分项报价单，可直接写进技术方案
