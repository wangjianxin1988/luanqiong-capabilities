## 怎么合作（总包 / 联合体 / 分包都可以谈）

我们处在产业链中间层，**不排斥任何规模的项目，也不堵任何一条路**：

| 你的情况 | 我们能怎么配合 |
|---|---|
| 你是集成商/总包，已中标 | 我们做技术分包：三维、仿真、UE5、后台对接，交付源代码 |
| 你缺投标资质 | 我们可以协助对接有资质的集成商/总包，由对方投标、我们做技术交付；联合体、分包、顾问式参与都可以谈 |
| 你是院校/甲方，要直接采购 | 可以按功能项直接报价；需要走招标的，我们配合提供技术方案与参数 |
| 项目太大或太小 | 大项目可以拆包、多家配合；小项目可以只做其中一段（比如只做三维制作与渲染） |
| 只买现成软件授权 | 我们主要做定制，但如果有标准化模块可以单独授权，也欢迎聊 |

> 一句话：**能做技术就做技术，做不了主体就帮你想办法把主体凑齐。** 不承诺中标（这不合规），但愿意一起把项目做成。
